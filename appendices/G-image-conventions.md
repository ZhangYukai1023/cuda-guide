# 附录 G：图像边界、坐标、格式与质量指标

图像处理里“均值”“双线性”“SSIM”这些名称不足以确定逐像素结果。输入格式、通道次序、stride、边界、坐标、核方向、舍入和指标窗口都属于接口。本附录与第 21—26、38 章的约定保持一致；对照第三方库前应逐项核对。

## G.1 图像内存与格式

单通道行优先 `u8` 图像位置 `(x,y)` 的线性偏移是 `y*width+x`；交织 RGB 则为 `(y*width+x)*3+c`。若实际每行有 `pitch` 字节或子图 ROI 起点，则行首是 `base+y*pitch`，再加 `x*channels+c`；不能用逻辑宽度代替物理 stride。Planar 布局是每个通道一整张平面，NCHW/NHWC 的 batch/通道偏移另有公式；GPU 核心数组需与 Host 的布局说明一致。

本书 PNM 示例使用二进制 P5 灰度与 P6 RGB，最大值 255，像素为 8 位；P5 的 `width*height` 字节和 P6 的 `width*height*3` 字节要严格检查。BGR 与 RGB 两个格式元素数量相同，但通道意义相反；RGBA 的 alpha 是第四通道，若把 alpha 当颜色参与均值滤波或灰度转换，应有明确理由。Alpha 可为 straight 或 premultiplied，透明边缘重采样方式不同。`.f32` 原始张量不含宽高/stride/字节序元数据，必须配 manifest；第 26/38 章规定行优先小端 IEEE FP32，归一化 `2*v/255-1`。

## G.2 边界取样

对长度 `n` 的一维索引 `i`，常见规则如下；二维分别对 x/y 应用：

| 规则 | 左侧 `i=-1` | 右侧 `i=n` | 说明 |
| --- | --- | --- | --- |
| Zero/constant | 取固定值 0（或指定常数） | 同左 | 扩散/FFT 补零常用，边缘能量会变化 |
| Clamp/replicate | 映射到 0 | 映射到 `n-1` | 重复最外像素；第 22—24、26 章多用此规则 |
| Reflect101 | 映射到 1 | 映射到 `n-2` | 不重复边缘像素；`n=1` 需单独定义 |
| Wrap | 映射到 `n-1` | 映射到 0 | 周期边界；FFT 未补零的循环卷积近似此语义 |

对于 3×3 核，左上角最多 5 个邻居在原图外，四种规则会产生不同结果。`reflect101` 与有些库称作 `reflect` 的“重复边缘像素”并不同；请用一个 3×3 手算图在接口边界测试。第 22 章的均值例给出左上角在零/复制/reflect101 下分别为 18/28/48。共享内存 tile 的 Halo 不只是性能结构，还承担把**正确边界值**带进 block 的语义责任。

## G.3 缩放与坐标

本书缩放采用整数坐标表示像素中心的半像素映射：

```text
sx = (x_dst + 0.5) * source_width  / target_width  - 0.5
sy = (y_dst + 0.5) * source_height / target_height - 0.5
```

最近邻取 `floor(s+0.5)`；双线性用 `floor(sx),floor(sy)` 的四邻像素按小数权重插值，再按边界规则映射；双三次用 4×4 邻域，可能过冲，写入 `u8` 前要饱和。第 24 章浮点插值的 8 位舍入为 `floor(v+0.5)` 然后限制到 `[0,255]`。面积缩小按目标像素在源域覆盖面积加权，是抗混叠实验，不与双线性逐像素相等。不同库可能使用角点对齐公式 `x_dst*(source_width-1)/(target_width-1)`、不同最近邻取整或预滤波；只有模式一致才比较结果。

几何变换通常以**逆映射**计算每个目标像素的源位置，避免前向映射出现洞。输出尺寸取整、ROI 和无效源位置填充值也要固定。颜色图像若在编码的 sRGB 值上插值，与先转线性光再插值不同；本书简单示例处理编码的 8 位值，没有实现色彩管理。

## G.4 质量和正确性指标

与干净参考图比较时，`MSE=(1/N)Σ(ref_i-output_i)²`，8 位动态范围 `L=255` 的 `PSNR=10 log10(L²/MSE)`；若 MSE 为 0，PSNR 记为正无穷。PSNR 高说明均方误差小，不自动意味着边缘/纹理视觉更好。没有干净参考时，不能把有噪输入冒充 ground truth 计算“去噪 PSNR”。输出相对 CPU 实现的最大差、超容差像素数是**正确性**；相对干净图的 PSNR/SSIM 是**图像质量**，两者目的不同。

第 23 章的 `SSIM8` 明确定义为 64×64 灰度图的非重叠 8×8 窗口 SSIM 均值。每窗取两个图的亮度均值 `μx,μy`、总体方差 `σx²,σy²` 和总体协方差 `σxy`，用

```text
SSIM = ((2 μx μy + C1)(2 σxy + C2)) /
       ((μx² + μy² + C1)(σx² + σy² + C2))
C1=(0.01*255)², C2=(0.03*255)²
```

它没有高斯窗口、滑窗重叠或多尺度处理，不应直接与库默认 SSIM 数字比较。局部边界、棋盘格和细纹理最好保存预览、差异图与放大区域一起观察；平均指标可能掩盖局部严重问题。

## G.5 交付时的一行契约

建议每个图像入口写成：`P5/P6; WxH; channels; dtype/range; row pitch/ROI; border; filter kernel/correlation or convolution; coordinate mapping; rounding/saturation; output shape/format; CPU/reference implementation; tolerance; quality metric version`。若其中任一项改变，应重新算参考与质量指标，不能沿用旧 PASS。
