# 第 32 章：FFT 与频域计算

[全书导航](../../README.md) · [原始大纲](../../outline.md) · [上一章](../ch31-linear-sparse-solvers/README.md)

本章用 [fft_frequency.cu](examples/fft_frequency.cu) 完成五个连续实验：两条短信号批处理 C2C 变换及往返、实信号 R2C/C2R、移除一维指定频段、二维频域低通，以及补零后的频域卷积与 CPU 空间域卷积对照。zyk 当前 Toolkit 缺 cuFFT 开发文件，因此上述 cuFFT 源码尚未构建或 GPU 实测。本章另有 [direct_frequency.cu](examples/direct_frequency.cu)，用普通 CUDA 直接 DFT 展示频谱、逆变换、低通与补零线性卷积；已在 zyk 编译并与 CPU 双精度/解析参考对照通过，见[验证记录](results/validation.md)。直接 DFT 为 O(N²) 教学实现，不能替代 cuFFT 的性能或完整接口验证。

## 1. 从 8 点信号看频谱

长度为 `N` 的离散变换采用

```text
X[k] = sum_{t=0}^{N-1} x[t] exp(-j 2πkt/N)
x[t] = (1/N) sum_{k=0}^{N-1} X[k] exp(+j 2πkt/N)
```

`x=[1,0,0,0,0,0,0,0]` 的八个频谱值都为 `1+0j`。另一个批处理输入是 `0.5+sin(2πt/8)`；CPU 直接用双精度求和计算 DFT，逐频点对照 GPU 输出。cuFFT 的逆变换**不自动除以 N**，因此往返后必须执行 `1/N` 归一化；二维图像除以 `width*height`。示例用相同的 8 点 C2C 计划执行两个相邻批次，也用单个计划做同尺寸的正向、逆向和频域卷积的多次变换。计划创建与工作区分配属于准备成本，不能算进单次 FFT 的纯执行时间后再与一次性的空间卷积直接比较。

实数输入有厄米对称：`X[N-k]=conj(X[k])`。一维 R2C 输出只存非冗余的 `floor(N/2)+1` 个复数；8 点例子是 5 个，`k=0` 和 `k=4` 在纯实信号下应只有实部。示例采用**非原地** R2C/C2R，给输入分配 8 个 `float`、频谱分配 5 个 `cufftComplex`，不借用原地格式的额外填充。CPU DFT 只比较这五个频点；C2R 之后同样除以 8。

## 2. 计划、批处理和工作区

`cufftCreate` 后先调用 `cufftSetAutoAllocation(plan,0)`，再用 `cufftMakePlan1d` 或 `cufftMakePlan2d` 确定计划和所需工作区字节数。示例显式分配设备工作区，传给 `cufftSetWorkArea`，在销毁计划后释放。每个计划与工作区的生命周期由 `Plan` 管理；数据缓冲由 `Buffer` 管理。如果真实输入尺寸、批次数或变换类型改变，应重新规划，不能复用不匹配的计划。本例批处理的两个长度 8 序列连续紧凑存放；复杂 stride、嵌入维度和不同批距需要 `cufftPlanMany` 或 `cufftMakePlanMany` 显式描述。

`cufftExec*` 与后续 kernel 在同一默认流中按顺序执行；设备到主机的同步拷贝之后才检查结果。以后改用非默认流时，应在计划上设置同一流，并保证工作区在所有操作完成前不被复用或释放。cuFFT 计划的工作区大小不是简单的输入字节数，实际打印 `workspace_bytes`，不要写死经验值。示例只演示相同类型同尺寸的计划复用，没有做多线程共享计划。

## 3. 频谱布局和二维滤波

cuFFT 的普通输出为**未平移**频谱：零频在索引 0，正频率接着排列，负频率回卷到末端。对偶数 `N`，索引 `N/2` 是 Nyquist 频率；低通判断用 `i<=N/2 ? i : i-N`。频谱图中把零频移到中心的 `fftshift` 只是显示/索引重排，不能对未移动的数据套中心圆形 mask。

一维信号长 64，包含 `sin(2π·3t/64)+0.5sin(2π·12t/64)`。GPU 保留 `|k|<=8`，因此 CPU 解析参考是仅剩的 `k=3` 正弦。二维 16×16 信号由常数、低频 `cos(2π(x+2y)/16)` 和高频 `0.4sin(2π(5x+4y)/16)` 构成；二维低通保留 `|fx|<=2 && |fy|<=2`，CPU 参考是常数加低频项。低通阈值以两个轴的离散频率定义，矩形通带可能有振铃；真实图像要考虑取样频率、截止频率单位、边界不连续和期望的滤波器响应，不能直接把这些索引阈值当物理频率。

## 4. 卷积定理、填充和边界

将长度 8 信号 `1..8` 与长度 3 核 `[1,-2,1]` 做**完整线性卷积**，输出应有 `8+3-1=10` 个元素。频域实现先将两者补零到长度 16，分别 FFT，频点相乘，再 IFFT 并除以 16；CPU 参考按 `out[i+j]+=signal[i]*kernel[j]` 直接求和。代码还检查末端填充区应接近 0。这里的核不翻转：`out[t]=Σ_i signal[i] kernel[t-i]` 是数学卷积定义；多数图像处理接口称为“卷积”的操作实际做相关 `out[x]=Σ_j image[x+j] kernel[j]`，对于非对称核必须明确翻转约定。

若不补到至少 `N+K-1`，DFT 相乘得到的是**循环卷积**，头尾会相互卷绕。补零也并不自动实现第 22 章的 `clamp`、`reflect101` 等图像边界：本例等价于域外为零。二维频域卷积还要确定核中心如何放进补零数组、裁剪 `full/same/valid` 哪个区域，以及对每个通道如何处理；只有把空间域与频域的这些定义完全对齐，输出才能逐像素比较。小核、小图像通常不值得付计划、变换和额外内存成本；大核、重复使用同一核或批量变换才值得量测频域方案。

## 5. 构建、运行和判定

在远程仓库根目录，按 zyk 之前使用的 CUDA 路径和架构配置：

```bash
cmake -S chapters/ch32-fft-frequency/examples -B build/ch32 \
  -DCMAKE_CUDA_COMPILER=/home/zhangyukai/.local/cuda/bin/nvcc \
  -DCMAKE_CUDA_ARCHITECTURES=120 -DCMAKE_BUILD_TYPE=Release
cmake --build build/ch32 -j
ctest --test-dir build/ch32 --output-on-failure
./build/ch32/direct_frequency
# 仅当 CMake 配置检测到 cuFFT 开发库时，再运行：
./build/ch32/fft_frequency
```

cuFFT 程序在可构建时打印 GPU 名、批处理与 R2C 的频谱误差、各往返/滤波/卷积的最大绝对误差、计划工作区字节，全部低于源码阈值时才打印 `chapter 32 FFT and frequency: PASS` 并返回 0。当前 zyk 只运行直接 DFT 教学程序，输出短序列正向/往返、一维低通和补零线性卷积的误差；批处理、R2C/C2R、二维低通和 cuFFT 计划/工作区仍未实测。cuFFT 路径的 CPU 对照包括短信号直接 DFT、解析可知的一维和二维纯净信号，以及空间域完整卷积；输出还检查虚部残差和卷积补零尾部。不能用一次小输入的运行时间证明 FFT 比空间域更快。真实性能比较应预热、重复计时、区分计划创建、主机设备传输、FFT 执行、频域相乘和裁剪，并在相同精度、边界、批量规模下比较。

API 的计划/工作区、变换方向及布局约定见 NVIDIA [cuFFT 12.8 文档](https://docs.nvidia.com/cuda/archive/12.8.0/cufft/contents.html)。具体 zyk Toolkit 行为以实测及本机头文件为准。

## 6. 常见错误

- IFFT 忘记除以 `N` 或二维的 `width*height`，误差恰好随变换大小放大。
- 把 R2C 输出当作 `N` 个复数，或在原地 R2C/C2R 时没有按文档提供物理填充。
- 将未平移频谱当作零频居中的显示图，导致低通误删直流与低频。
- 用 `N` 点 FFT 做长度 `N` 与 `K` 的线性卷积，得到循环卷积却与 CPU 线性卷积比较。
- 卷积和相关、零填充和镜像/钳制边界、完整输出和 `same` 裁剪混用。
- 计划变更输入维度后仍复用；设备工作区被提早释放，或跨流并发复用同一计划/工作区。
- 只检查往返。正向和逆向同犯一个布局错误时，往返可能掩盖它；所以另有 CPU DFT 和解析/空间域参考。

## 7. 练习与参考答案

1. `N=8` 的实信号 R2C 需要几个复数频点？`k=7` 的频率位置在哪里？答：`8/2+1=5` 个；`k=7` 等价于频率 `-1`，其值是 `k=1` 频点的共轭，不单独存储。
2. 长度 8 与长度 3 的序列做完整线性卷积，FFT 最短可用长度是多少？本例为何选 16？答：至少 `8+3-1=10`；16 是方便的补零长度，不是正确性的必要条件。
3. 16×16 图像的逆变换若未归一化，输出放大几倍？答：256 倍。
4. 把本章频域低通与第 22 章空间滤波逐像素比较时，应先统一什么？答：滤波核及翻转/相关约定、域外边界、输出裁剪、通道与浮点精度；频域掩模也必须对应同一个空间滤波核的频率响应。
5. 若要把长度 8 的两个批次改成每批起点相隔 12 个复数，原 `cufftMakePlan1d(...,batch=2)` 的紧凑布局是否仍正确？答：不正确；要用 `cufftMakePlanMany` 描述批距 `idist/odist=12`，或先整理成紧凑缓冲。
